# 桌面前端重建基线

> 历史清理记录，已被后续桌面接线与 2026-09-08 旧系统清理覆盖：新桌面可用 `pnpm dev:desktop` 开发启动，Renderer 构建已启用；旧依赖和旧静态产物已清理。只有正式发布验收门禁仍保留。下文“本批”指最初删除旧前端的批次，不代表当前状态。

## 已确认范围

这是产品重设计，不是旧 Web 页面的换皮。用户已批准删除旧前端，并选择“智能体对话为主，任务与证据按需展开”。用户随后通过截图锁定“行动谱面”，精致程度对标 Claude Desktop / ChatGPT 桌面端；不是常规助手方向。产品事实见根目录 PRODUCT.md；具体精细布局待确认。

## 本批清理

删除 apps/web 的 42 个受 Git 跟踪的旧实现文件，包含页面、组件、样式、状态、API 客户端、旧 UI 测试与 Vite/TypeScript 配置。保留 package.json 作为显式停用入口；依赖与 lockfile 暂不裁剪，避免本批顺带变更其他工作区依赖。

旧源码可从 Git HEAD 恢复。本批不删除本机数据、密钥、Scenario、Core 或当前宿主实现，也不触碰其他尚未提交的模型与黑盒更新。可能存在的被忽略 dist/node_modules 缓存不是新产品资产，本批未递归删除；标准启动/构建/打包入口均设有停用围栏，不能继续使用旧产物。直接绕过项目脚本运行旧二进制不在此围栏范围内。

桌面入口在初始化数据和启动服务前报告前端已移除；旧 Web dev/build 与 Desktop pack/dist/release 命令明确失败。Desktop TypeScript 编译和 build:foundation 仍用于核验保留代码。根目录递归 build/verify:release 目前不能作为可发布成功基线。新 renderer 接通时必须一起替换旧 web 资源路径、打包资源配置、依赖与围栏，不得只去掉报错。

## 新交互要求（非视觉定稿）

- 对话承载用户意图、进度摘要、补充说明与结果解释，不把原始日志或底座对象逐项倒入聊天。
- 任务与证据由对话中的操作和引用按需展开；收起不丢状态，查看证据不丢输入草稿和对话位置。
- 待审批、阻塞和失败必须在主视图可发现。自然语言描述不能被前端直接当成批准或执行成功。
- 任务、模型和场景选择必须有明确作用域；切换不能让旧任务的迟到事件写入当前对话。
- 重连先恢复真实快照和事件位置；已发送但未知结果的操作不能自动重新提交。
- 设置在用户主动进入时显示。供应商、Skills、知识资源和 MCP 不默认占据主工作区。
- 专业证据视图由场景扩展；通用桌面壳不假定目标一定是网址。

## 当前接口证据与缺口

后续审查已细化到请求字段、状态语义与缺口，见 [对话优先桌面：交互与接线审查](desktop-interaction-contract.md)。下表为清理批次的初始摘要；新增审查没有声称对话接口已经实现。

这些是读源码确认的能力线索，不是新前端可直接复用旧客户端的承诺：

| 功能 | 当前代码依据 | 接线前需要确认 |
| --- | --- | --- |
| 模型配置/测试 | apps/server/src/routes.ts 的 /api/config/llm 及 test/suppliers | 返回字段、凭据脱敏、错误与配置生效范围；订阅登录未完成 |
| 场景与 Run | apps/server/src/scenario-routes.ts 的 definitions/runs | 创建输入、授权前提、暂停/恢复/取消的真实语义 |
| 人工审批 | 同文件 approvals/resolve | 人工身份、作用域、失效与重复提交 |
| 本机权限桥接 | apps/desktop/src/main.ts 与 foundation-host-control.ts | 新 renderer 的最小权限桥接，不暴露宿主凭据 |
| 对话命令与恢复 | 尚未完成独立合同审查 | 不假定已有完整持久化聊天 API；需要用户意图到 Run 的明确适配 |
| 证据详情与事件展示 | 尚未完成独立合同审查 | 引用解析、分页、事件补发、脱敏和场景视图边界 |

旧 Case 路由即使仍存在，也不是新信息架构的默认模型。不得顺便重建旧业务后端；新增宿主适配必须证明需求并保持 Core 无界面依赖。

## 下一完整交付

先确认新的对话主工作台原型及当前宿主合同清单，再一次贯通“配置模型 → 发起授权调查 → 对话观察 → 人工审批 → 查看引用证据 → 关闭后恢复”。视觉风格与具体面板位置需要原型确认，不继承旧界面。缺少真实模型授权时只做明确标注的受控验收，不宣称模型自主调查通过。

实际作用：用户主要在对话中工作，需要核查时才打开结构化任务和证据，同时不丢失审批、恢复与执行安全边界。

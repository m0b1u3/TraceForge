# TraceForge 桌面工作台界面合同

更新日期：2026-09-24。本页只描述当前 `HostWorkbench`。整体视觉和入口见 [DESIGN.md](../DESIGN.md)，运行与验收边界见[当前开发状态](development-status-and-roadmap.md)。

## 对话与任务

会话导航、连续对话和输入是主界面。用户消息居右，智能体回复居左；任务、证据和工具过程按需展开。输入统一发给助手，任务提案绑定原始用户消息。紧凑确认窗展示原任务、默认场景与已保存偏好；用户明确允许后才创建授权并开始。设置只保存下次任务的偏好，不自行授予权限；危险、越界或未知执行结果仍由原有合同处理。思考和工具细节默认收起，回复停止保留在输入区，停止任务与撤回排队回复是独立操作。

已保存回复增量显示。失败、中断或停止保留收到的文字，不自动续写；只读历史、附件和证据材料可在侧栏打开。长正文限制阅读宽度，Markdown 原始 HTML 不执行，远程图像不自动加载。切换会话和窄屏面板后保留各自草稿与阅读位置。附件选择、取消、失败和键盘操作显示明确反馈。

## 设置与恢复

模型连接、任务执行、场景资源、Skills、MCP 与数据/日志从设置进入。保存配置不隐式连接 MCP 或执行工具；运行只消费新 Run 固定的有效版本。敏感值不进入 Renderer 快照。错误保留输入并允许重试或核对，未确认的请求不能换命令 ID 自动重发。

数据与日志页面分别展示应用数据、诊断日志与界面 HTTP 缓存。清理缓存不删除对话、证据、工作文件、Cookie 或模型登录。空间统计为部分统计时明确标注。界面与宿主异常时展示实际状态，不用示例消息覆盖错误。

## 原生任务浏览器

有活动浏览器会话时，真实网页在同一 Electron 窗口右侧显示，左侧保留对话。人工接管和交回只切换控制权；交回后同一页面仍可供智能体观察。智能体控制时拦截人工键鼠输入，接管时显示控制状态。用户主动收起页面不会结束会话；新的接管请求会明确提示。

原生 WebContentsView 保持页面沙箱和宿主工具栏边界，页面没有桌面桥接或 Node。页面元素视图只显示文本和可操作控件，不把远程 HTML 装进宿主。操作结果未知时禁用重复提交并提供状态核对；浏览器清理未确认时保留显式“重试关闭”，不自动重放页面操作。

宽窗口保持对话与网页并列，较窄窗口让页面覆盖主内容并提供返回。工具栏地址隐藏查询与片段；弹窗与确认层出现时隐藏原生页面，避免覆盖宿主控件。`BrowserWindow.capturePage()` 不含原生子视图，因此这类 PNG 只记录宿主布局；网页可见性以原生窗口检查为准。

## 验收口径

组件断言与合成截图只验证界面状态。独立原生夹具已覆盖实际 WebContentsView 显示、输入、交回、同页 DOM 回读和沙箱；最近隔离的 `deepseek-flash` 本机网页任务完成了正常对话入口的浏览器交接，但 Run 由用户停止，没有自然完成。正式发行与真实安全发现仍需单独验收。

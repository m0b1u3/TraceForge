# 模型与任务默认限制整改

2026-09-21。范围是阻断正常模型生成和任务推进的产品默认限制，不是取消用户授权或宿主隔离。

| 检查项 | 整改结果 |
| --- | --- |
| 接入层将本地压缩预留写成 `max_tokens` | 删除。请求只使用接入配置/保存的模型能力声明；Chat Completions、Responses 未声明则省略该参数。 |
| 模型能力声明被 `min(4096, window/8, declared)` 压低 | 删除。使用声明值，不再偷偷降低。 |
| Anthropic 缺少配置时回退 4096 | 删除。该协议要求此字段，缺少模型输出声明时明确报配置缺失，不发送伪造值。 |
| 未知模型按假定窗口拒绝输入 | 删除接入层和对话层的此类本地拒绝。未知窗口的保守值仅供历史整理估算，不宣称是模型能力。 |
| Planner/Observer/Worker 的累计 token 和单次估算配额 | 删除默认配额。明确配置仍生效；用量记录、调用回执保留。 |
| 角色默认 90/120 秒、对话默认 4 分钟 | 删除默认总时限。明确配置、用户停止、撤权、宿主关闭仍能取消调用。网络传输故障仍报错。 |
| 对话 8 轮、6 次工具调用 | 删除。协议层回读计数和活动展示同步，不因超过 6 次而解析失败或隐藏后续活动。 |
| Worker 默认 24 轮，长任务默认 240 轮/120 分钟 | 删除默认累计上限。任务可选字段留空即不设置；明确预算及已保存授权不被覆盖。24 轮可继续作为持久分段间隔，不作为总回合限制。 |
| 摘要压缩默认 1 秒/120 秒、收尾默认 10 秒 | 删除默认模型总时限。显式超时配置与取消信号保留。 |
| 单条回复 64 KiB 截断 | 删除。长回复、历史原文协议不再沿用这一输出长度限制。 |

## 保留并明确区分

- 用户授权的目标、操作、凭据、文件范围、到期时间；既有 Run 的固定授权快照，不因软件默认值变化而扩大。
- 工具的单次操作合同、网络响应大小/分页、沙箱和进程所有权；不是模型的累计 token 配额。
- 停止/撤权、未知执行结果不重放、重复失败与失控重试保护、供应商实际返回的能力/协议限制。
- 本机容量与展示保护仍存在：队列准入、推理展示截短、工具结果摘要及分页。本文最初记录的回复全库 32 MiB/10000 条累计门槛已在 2026-09-23 后续整改中移除，改由物理磁盘准入保护新增和增长的回复；磁盘压力仍使用独立 `storage_limit` 状态，不伪称供应商输出达到上限。配置、资源和来源记录的同类历史累计门槛也已移除，详见开发状态页顶部。
- 测试夹具的有限样本数和超时属于测试的终止条件，不进入产品默认运行策略。

## 验证边界

定向测试覆盖超过旧 8 轮/6 次调用、超过旧 64 KiB 输出、默认 4 分钟后仍可等待且可取消、Agent 超过 240 回合完成、模型声明 384000 不被压为 4096、未声明时请求不带输出参数、可选任务预算留空、原有显式预算及停止/撤权回归。

本批为代码与确定性测试验证；此前 DeepSeek 浏览器接管验收已暂停，不将这些测试替代真实接管成功。

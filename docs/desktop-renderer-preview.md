# 行动谱面桌面交互预览

> 本页保留独立设计预览的历史说明；当前桌面已另有真实 HostWorkbench 与 IPC 接线，可通过 `pnpm dev:desktop` 启动。独立预览仍不能当作真实执行验收。正式打包门禁未解除。

本页记录独立 renderer 预览，不是已经接通智能体的正式桌面应用。

## 运行

在仓库根目录执行 `pnpm --filter @traceforge/web preview:desktop`，仅监听 `http://127.0.0.1:5178/`；构建执行 `pnpm --filter @traceforge/web build:desktop-preview`。依赖容器沿用 apps/web/package.json，但源码全新位于 apps/web/renderer，输出为 renderer/dist，未恢复旧 src 或旧 Web 开发/构建命令。

## 已实现

- 用户确认 A 并列核查；随后要求用户消息居右、智能体回复居左，已覆盖原图对应排列。保持左侧窄导航、中央对话、可收起的证据/任务与最右行动轨。
- 中性观察引用、来源展开、任务列表、审批详情、模拟确认/暂缓、对话输入、字数/条数上限、设置说明及带确认的重置。
- Enter 添加本页记录，Shift+Enter 换行，组合输入事件与 229 键码不会发送；输入只作纯文本呈现，聊天中的“可以”不能改变审批状态。
- 使用当前标签页 sessionStorage 恢复草稿、手动输入的预览消息、面板和模拟决定；数据有版本、类型与大小校验。存储失败/损坏有明确提示；不读取真实宿主档案，不存凭据，不承诺跨标签页或关闭后的恢复。
- 窄窗口收敛为对话/侧区切换，底部导航保留；来源展开、收起与模态框有焦点处理，模态框支持 Escape 和焦点约束。

## 解耦与真实性

preview-state.ts 为纯展示状态；没有依赖 Core、Scenario、Host 客户端或模型凭据。workbench.tsx 只消费预览状态，所有初始记录与时间均为合成示例。发送不生成假的智能体回答；模拟确认不发送审批请求、不执行工具，任务始终未执行、观察始终待验证。附件读取和模型设置接线明确未支持。

apps/desktop 的正式启动、旧 Web 命令和发行入口继续失败关闭，避免新预览或残留旧 dist 被当成已完成产品。不要通过预览测试解除围栏。

## 下一完整目标与验收

依据 desktop-interaction-contract.md，在桌面宿主适配层接通模型配置、授权调查、对话消息/事件、审批和证据读取以及退出恢复。不将现有执行事件直接伪装成完整聊天协议，不将模型配置伪装成会话级设置，不改动底座授权和证据验证语义。

实际作用：用户可以在同一个对话窗口开展调查，在需要时看任务、依据和进度；刷新或重启后不丢工作，也不会把“请求已发出”误认成“操作已成功”。验收必须区分真实宿主/模型回执、未送达、请求结果未知和演示状态；模型与平台实机验收仍未完成。

# macOS 原生桌面联合验收记录

环境：macOS Apple Silicon、Electron 37.10.3；生产桌面入口，隔离 userData，沿用 OS 加密保存的 Grok 模型配置。通过原生 UI 操作，不注入 renderer 脚本，不使用合成模型替代本次对话。

## 实际通过

- 同一会话发送中性验收记录，看到真实流式回复、模型公开 reasoning 和工具活动。
- 请求读取历史原文，实际出现 `conversation_read`，回复准确包含测试标记，界面显示已读取 1 段。
- 生成期间发送补充消息，出现待处理状态；前一回复完成后自动接续。另一次生成期间排队后点击停止，部分正文保留，待处理回复也被取消，未继续生成。
- 使用 macOS 原生文件选择器添加仓库内专门创建的无敏感文本附件；保存后点击附件，在同一对话侧栏显示精确内容。
- 正常退出整个应用并从同一隔离目录重开：原会话、完成回复、停止状态、工具记录及附件均保留；界面没有自动续写，再次点击附件可读取相同内容。
- 原生设置页的模型、场景与扩展、MCP 页面能打开。无已安装场景时明确显示依赖条件，未隐式安装或连接服务。

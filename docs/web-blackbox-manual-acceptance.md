# 黑盒 Scenario 手动验收

本批不连接外部 CTF，不调用真实模型；自动回归使用受控本机夹具。手动验收面向 macOS Apple Silicon 桌面，不代表 Linux 验收或正式安装包已完成。

## 准备

启动 `pnpm dev:desktop`，在模型设置确认可用模型。使用可重置目标，记录目标、预期交付物与需要检查的行为。桌面输入目标即启动任务，不需要在表单中填写 URL 白名单。需要身份时在宿主配置身份句柄，不把密码填入普通工具参数。

当前桌面内置 Web 场景随应用构建固定装载。新任务直接使用场景默认配置；旧任务偏好不会阻止启动。已绑定的旧 Run 在有效期内继续使用自己的包和执行归属，恢复时也不再检查旧的操作勾选或资源白名单。缺失旧程序材料时仍须显式恢复。

### 工具联网验收

工作区脚本默认可直连网络，在本次 Run 工作区下载并执行文件，不逐站点审批。直接连接不产生逐目的地网络回执，执行回执记录 `network: direct`。结构化 Web 请求和桌面 MCP 仍遵守各自的传输合同，不能把传输成功当作安全发现。

使用可控测试服务，让模型保存工作区脚本，通过本机 `curl` 直接下载文件到本次 Run 工作区，再执行下载的测试脚本。确认域名解析与直连可用、运行中停止或撤权会终止进程。核对工具回执中的直连模式、脚本输出和下载文件的内容身份；不要把直连进程回执说成逐连接或逐请求证据。当前自动启动的脚本时长预算为 3600 秒；场景 HTTP 工具仍有独立的累计预算。

这条能力允许在工作区下载并执行已适配本机及沙箱文件范围的内容；不代表主机工具目录、任意解释器、跨 Run 安装或复杂浏览器登录已完成。自动验证的 HTTPS 使用本机临时证书和明确 CA 校验，没有修改系统信任或禁用证书校验。

### 客户端指导资源验收

在“设置 → 场景与扩展”选择已审核的场景，修改包内指导并新建自己的 Skill/角色指导/知识资料，选定其父资源、角色和阶段，保存配置。也可导入 UTF-8 Markdown/TXT；已有正文须确认替换，删除须再次确认。待确认期间保存和重新读取应不可用。

开始新任务后核对 context.catalog/read 的实际资源 ID、摘要和正文与保存修订一致；再修改或删除该资源，旧任务应仍读原内容，新任务使用新修订。父资源停用或撤销时，相应用户资源不能绕过读取边界。角色指导目前作为上下文资料，不替换系统提示词；导入不会执行 Markdown 中的脚本。MCP 新连接、凭证与显式发现测试已有界面和宿主实现；实际服务兼容性仍须独立验收，不以配置保存视为通过。

## 一次完整流程

1. 在桌面输入目标并发送。检查 Run 自动启动，模型识别目标和可用工具，界面不要求范围核对或工具审批。
2. 查看探索输出：链接可以进入有界队列，表单只显示方法、动作地址和字段名，不应自动提交，也不应泄露字段值。动态页面能力不足时应明确说明。
3. 提供或观察至少两个独立疑点。检查它们都成为独立假设，只有一个验证任务执行；进度能解释当前正在验证什么。
4. 让一次验证按请求预算暂停再继续。检查使用原候选/Work/计划，准备请求不重复，控制与候选观察都进入证据。
5. 在另一个独立测试 Run 中验证停止/断开情况。不要对有副作用的真实目标故意制造未知结果；可在可重置本地夹具模拟丢响应。未知效果应显示为阻塞，重启和写入 inconclusive 复核都不能自动重发。
6. 查看复核和报告：支持的候选不等于已验证漏洞；会话探索、遗漏、未完成候选和浏览器覆盖限制应保留。点击引用确认能找到真实证据。若用户目标是获得特定结果，需要有归属明确的证据，不能只根据页面宣称成功。

## 反馈格式

提供 Run ID、Scenario 版本、模型、失败阶段、相关工具名、预期行为、实际行为及证据引用。涉及凭据先脱敏。不要只发最终回答截图：保留最后一次成功操作、待确认操作和停止原因，才能区分场景策略、模型行为、工具能力与宿主问题。

## 尚不能据此宣称完成的能力

当前对照执行是一次性前置请求加重复 HTTP 单维度对照（含普通正文和非凭据请求头），不支持每轮重置；不等于任意多步利用、可交互浏览器登录、任意 CLI 工具、资产测绘或指纹识别全覆盖。报告构建器不会自动读取或推进 Finding 生命周期。真实模型调查效果和 macOS 桌面全流程以本次手动结果为准，不能拿夹具通过代替。

# TraceForge 当前开发状态与下一步

更新日期：2026-09-28。本文件只记录当前事实、未完成项和下一优先级。早期批次的覆盖式计划已清除；已完成的实现以源码、测试及相应架构文档为准。

## 产品与架构边界

TraceForge 是 macOS Apple Silicon 优先的桌面 AI 安全智能体。对话是主要入口，任务、工具活动和证据按需展开。Server、通用 Foundation 和 Scenario Process 支持桌面产品；场景声明自己的流程和工具合同，Core 不包含目标、漏洞或样本特判。当前桌面任务已移除应用内的操作选择、资源白名单和逐次工具审批：输入目标后自动启动，已安装工具可按 Work 调用。Scope 仍用于 Run 身份、归属、停止和撤销；模型不能自行安装工具或改变执行宿主。未知执行结果及来源失效继续按持久合同处理。远程执行节点、多用户平台和自动更新不在当前范围。

用户可在桌面编辑场景指导、Skills、知识绑定和 MCP 配置；资源默认值与用户修订分离，新 Run 固定当次生效配置。模型凭据留在宿主安全存储。桌面只提供受保护的宿主桥接，直接打开 Renderer 不显示模拟调查。

## 已实现的当前链路

- 统一对话入口、消息与回复持久化、增量展示、排队编辑、停止与重开回读已接入桌面。新任务使用已安装场景的当前默认配置自动登记 Run 身份并派发；旧偏好、过期字段和已关闭的操作不再阻断新任务。任务设置只选择默认场景，输入框不再显示审批开关，Worker 不再向模型提供权限申请工具。隔离的原生桌面模拟模型验收已从输入框发送单独目标，完成规划、目标请求、候选评估、证据复核与报告，并在同一对话显示结果；这不代表真实模型或任意目标已完成验收。
- 内置 Web 场景、Worker、工具发现、受控本机执行、回执、证据与上下文来源由现有合同连接。桌面直接装载应用固定资源目录中的这一个场景；外部场景的通用审核能力仍在 Server 中。Web 场景的页面或验证规则不写入 Foundation。
- Web 场景的独立 HTTP 对照与调查验证现共用包内请求解析、观察判定及限时执行围栏。多变体总体判定统一按截断、不稳定、可重复差异、无观察差异的顺序处理；准备步骤、候选账本和复核仍留在调查工作流。两个工具原有检查点、请求指纹及对外观察字段保持各自格式，内部 HTTP 结果直接传递对象。
- 当前运行时把已绑定 Scope 的应用层操作选择和资源范围展开为已安装工具可用，工作区脚本默认获得直连网络与交互终端，不再等待逐次审批；旧 Scope 恢复时也按此执行。macOS 原生隔离仍约束工作区文件、进程归属及清理；宿主持续检查 Run、租约和撤权，执行回执标记 `network: direct`。直连目的地及内容没有宿主逐连接回执，不能据此宣称单个请求已被观察或验证。结构化 Web、公共资料和桌面 MCP 仍走各自的网络传输合同，目标内容不是用户授权。
- 原生 Chromium WebContentsView 能在同一桌面窗口展示页面、人工接管、交回、读取同页 DOM 并清理。首次正式对话入口验收曾由用户停止，不能计为自然完成；随后使用隔离 `deepseek-flash` 与同一中性网页的完整复验已从对话、接管、保存、交回、证据回读走到 `run_completed`。该验收只证明这条授权操作链和持久终态，不证明安全发现或其他工具组合。
- 浏览器面板已按桌面对话工作台的白色阅读面重排：控制权、当前页面、交回与收起操作在同一清晰层级，窄窗口由网页占据主视图；交回成功时立即切换为智能体控制状态，避免旧接管标识触发短暂的连接错误。本机原生验收窗口使用明确标记的合成对话与中性网页，右侧仍是正式 `BrowserViewport` 和真实 `WebContentsView`。[本机实机截图](screenshots/native-browser-acceptance-2026-09-26.jpg)只证明该夹具中的原生界面呈现，不代表正式对话入口或真实目标验收。
- 历史累计门槛的清理已落地：资源/MCP 每 Run 绑定不再受全库 8192 条限制，上下文/Observer 记录不再受全库 8192/4096 条限制，配置历史不再受 2048 版/16 MiB 限制，对话创建不再受 1000 条限制，回复不再受全库 10000 条/32 MiB 池限制，来源项目获取不再受 64 次历史命令限制。旧容量触发器在数据库装配时替换，已有记录不删除；单条输入合同与物理存储准入仍生效。对话列表继续以 1000 条分页读取，流式回复遇存储不足保留已落盘内容并标记 `storage_limit`。
- 本轮扩展了同一原则：移除单会话 2000 条消息、附件与工具回读的全局累计池、上下文资源和记忆历史的固定累计门槛；上下文组装与历史摘要按页消费原始消息，摘要保存覆盖数和逐条来源校验。执行回执、进程记录、恢复/检查点、归档和进程占用的旧默认累计上限迁移为磁盘准入，显式自定义策略仍有效。队列命令、Scenario Artifact/State 默认累计门槛也移除，入库继续检查物理余量。
- Run 工作区可分页列目录、分段读取/追加文件，并以 SHA-256 前置条件原子替换大文件字节区间；脚本写入额度取当前磁盘可用空间，256 KiB 是单次工具传输页而非文件总上限。进程工具输入、执行节点默认写入额度与此同步，不再以 1 GiB 截断；请求和 CPU 时长使用宿主计时器可表示的上限，单进程输出额度为 16 MiB。浏览器会话累计请求/观察/动作和证据库累计条数/字节门槛已移除；单份证据传输上限从 4 MiB 提高到 64 MiB，前端控制帧、采集及读取链同步调整。桌面 stdio MCP 可在明确测试/启用后使用所选站点来源的宿主网络代理，单次请求和进程时长由连接设置指定；凭证留在宿主安全存储，指定环境变量时通过私有管道临时传入已审核的 macOS 沙箱子进程，不进入命令行参数。代理保存按连接和任务归属的网络回执，并在任务绑定撤销后拒绝新连接。
- 已退役旧 Web 应用、旧工具 PoC 和旧 MCP 直启入口；`scripts/verify-retired-code.mjs` 仍在测试与构建门禁中。本轮进一步删除无宿主时的独立演示工作台、模拟审批状态及其无引用样式；缺少桥接时显示明确诊断。旧设计草案、被覆盖的整改计划和临时生成文件已清理，仍由正式宿主使用的共享 CSS 保留；退役代码门禁新增对旧演示入口与状态模块的回归阻断。`build:renderer` 取代了旧 `build:desktop-preview` 命名；原生浏览器验收夹具在启动时重建自己的 JS/CSS/preload，不依赖遗留输出目录。

## 尚未完成与验收边界

1. **其他任务的自然收尾。** 本机中性网页的单项操作已实际自然完成；不同目标、失败/撤权与长任务仍需验证通用阶段完成判定。不要为这次页面样本添加特殊条件。
2. **本轮能力的原生端到端验收。** 代码与定向回归已覆盖长会话、工作区分页、MCP 网络代理和浏览器证据新额度；本机 macOS Seatbelt 组件测试已验证 MCP 凭证、代理请求与回执。还需在正式桌面入口验证本机大文件、真实浏览器大证据、实际 MCP 服务的配置到调用全链，观察磁盘不足、撤权和进程未知结果。64 MiB 浏览器单份证据和 256 KiB 工作区单次传输页仍是有界传输合同，超过单份浏览器证据额度需要分块采集协议。
3. **发布验收。** 正式桌面发行命令仍受发布门禁拦截。签名、打包、真实目标与平台隔离矩阵应在发布阶段分别核验；现有组件测试或合成截图不算正式发行验收。
4. **真实模型覆盖。** 最近通过的是隔离 `deepseek-flash` 的本机中性网页任务，不代表其他供应商、全部工具组合、长任务或安全发现验证。今后真实模型开发测试只用 DeepSeek，默认不改用户日常模型配置。
5. **资料与配置消费。** 桌面配置能力已有接线；新增或修改配置路径仍需以保存后的真实 Run 消费、版本固定、撤销与恢复验证，不能仅以表单保存视为完成。
6. **旧 Run 的程序材料。** 新桌面构建不再附带旧版本场景目录，旧 Run 的身份和记录保持原状；需要旧程序材料的未完成 Run 尚无自动恢复路径，必须显式迁移或保留相应材料，不能静默用新内置程序替换。
7. **工作区直连的桌面验收和可观察性。** 原生测试已证明本机下载后执行、公网域名解析及直连进程在撤权/Run 停止后被宿主终止；隔离桌面模拟模型已证明单独目标可自动登记 Scope、启动 Run，并完成规划、目标观察和报告对话结果。这条目标请求使用场景网络工具，尚未在正式桌面新 Run 中验收工作区直连脚本的下载、执行、停止与撤权，也未以真实模型复验直连。直连不经过宿主代理，无法提供逐目的地、响应或下载内容的网络回执；模型需另行保存命令、文件身份与输出作为证据。为支持本机系统 DNS，直连沙箱允许全局文件元数据查询，但文件内容读取仍按既有路径授权。主机工具目录、任意解释器和跨 Run 安装仍未实现；这些是执行能力缺口，不再由任务偏好控制。

## 下一明确优先级

下一步用可控本机服务验收自动启动后的工作区下载、执行、停止与撤权，确认回执只声明进程级直连模式。模拟模型的目标到报告对话结果已通过；需要用隔离 DeepSeek 配置复验真实模型的自主判断时，不改变用户日常模型配置。随后完成尚未覆盖的正式桌面全链：浏览器大证据、本机大文件、已启用的 stdio MCP 联网/凭证调用，以及磁盘不足、撤权和未知执行结果恢复；另处理需要旧场景程序材料的未完成 Run。中性单项浏览器任务的自然完成已通过实机，其他目标和长任务的通用收尾仍需检验。每批只记录实际完成的能力和相应证据。

后续原生验收继续核对 Run 归属、来源绑定、可回读证据和磁盘余量拒绝；测试通过前不能把新能力描述为真实桌面全链完成。失败、撤权和未知执行结果不能误写为完成。发布门禁仍按上面的独立缺口处理。
